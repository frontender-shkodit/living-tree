# Адаптивность — этап 4

Уточнены режимы 4/3/2/1 колонок каталога и поведение на границах 1000, 768 и 480 px. Декоративные исходные SVG-фоны теперь занимают всю высоту секции, включая дополнительные переносы текста на промежуточных ширинах; корневые атрибуты оригинальных SVG сохранены. Добавлен компактный режим шапки и перенос подвала для 320 px.

Мобильное меню закрывается по Escape с возвратом фокуса кнопке, клику вне шапки, выбору ссылки и при переходе к десктопной ширине. Кнопки меню и переключения отзыва имеют область нажатия не меньше 44 × 44 px.

Проверка Chrome охватывает 13 ширин: 320, 360, 479, 480, 600, 767, 768, 999, 1000, 1200, 1439, 1440, 1920. Проверяются число колонок, обрезка текста, горизонтальное переполнение, изображения и сценарии меню. Отчет: layout-check.json; скриншоты эталонных размеров: screenshots/landing-*.png.

Ограничение визуального соответствия сохраняется: оригинальный шрифт Sunday ещё не предоставлен. Отправка заявок и модальные окна относятся к последующим этапам.

# Подготовка проекта — этап 2

Подготовлены React + TypeScript + Vite, npm scripts, строгая проверка типов, базовый CSS и токены дизайна. Точные версии зависимостей закреплены в package-lock.json. Open Sans 300/400/500 с кириллицей и латиницей поставляется локально через @fontsource/open-sans; внешних запросов к Google Fonts нет.

Sunday не найден среди системных шрифтов. Нужен оригинальный файл с разрешённым веб-использованием, предпочтительно WOFF2. Пока задано только имя семейства в CSS-переменной; подмена другим шрифтом не считается соответствием макету. Верстку остальных элементов можно продолжать.

## Ассеты

Материалы скачаны по ссылкам из контекста, полученного на этапе 1. Новый экспорт Figma пока ограничен лимитом Starter. Исходные файлы не изменены. Скрипты загрузки содержат временные URL и служат записью происхождения, а не runtime-зависимостью сайта; повторное скачивание после истечения ссылок потребует нового контекста Figma.

Карта использования находится в src/data/assets.ts, фотографии связаны с товарами в src/data/products.ts. Имена photo1–photo9 соответствуют последовательности карточек из контекста 1000 px. photo.png — декоративный мох, а не товар. logo1.svg — шапка, logo.svg — подвал. icon9/icon12/icon11/icon10 — четыре пункта About в смысловом порядке. Каталог использует оригинальные волны для каждого размера, первый экран — пять исходных растровых вариантов.

SVG сохраняют оригинальные размеры; на этапе верстки проверять геометрию контейнеров, не менять корневые width/height. photo1.png имеет другую исходную ширину, поэтому кроп проверять отдельно по макету. Нарисованный курсор исключён из материалов для интерфейса.

## Проверка

- npm install завершён, аудит зависимостей: 0 уязвимостей.
- npm run build: проверка TypeScript и production-сборка успешны.
- Проверены ненулевой размер файлов, XML SVG и сигнатуры PNG; размеры записаны в asset-dimensions.json.
- Визуальная сверка применения ассетов будет выполняться на этапе 3, когда появятся секции сайта.

Текущая страница — временный экран подготовки. Следующий этап: верстка секций по макету. Для окончательного совпадения типографики остаётся файл Sunday.

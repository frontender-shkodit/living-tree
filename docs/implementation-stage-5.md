# Интерактивность — этап 5

Кнопка первого экрана открывает общую форму в модальном окне; кнопки карточек передают ID и название товара. Сохраняется отдельная форма внизу страницы. Диалог закрывается крестиком и Escape, удерживает клавиатурный фокус, блокирует прокрутку фона и возвращает фокус исходной кнопке. Панель прокручивается на низких экранах.

Форма проверяет имя и российский телефон, объясняет ошибки текстом и выделяет поля. Телефон приводится к +7XXXXXXXXXX; комментарий необязателен. Во время запроса кнопка блокируется, повторные submit не создают новую заявку. При ошибке введённые данные сохраняются; пользователь может повторить запрос. Тайм-аут — 15 секунд. Закрытие формы прерывает ожидающий запрос на клиенте; это не гарантирует отмену уже принятого сервером заказа.

Фронтенд подготовлен к POST /api/orders: JSON с name, phone, comment, product (ID и название либо null). Успех требует HTTP 2xx и JSON {"accepted": true}. Обработчик на этапе 6 ещё нужно реализовать; сейчас сайт сообщает об отсутствии подключения. Ответ без подтверждения не считается успехом.

Окно подтверждения использует оригинальную иконку из Figma, текст благодарности и кнопку закрытия. Проверка успеха выполняется только с подменённым ответом в браузере — реальные заявки не отправлялись.

Отзывы переключаются кнопкой, стрелками клавиатуры и горизонтальным свайпом. Вертикальные жесты сохраняют прокрутку страницы. Телефон и почта — действующие tel/mailto-ссылки. Соцсети оставлены заглушками по указанию пользователя.

Проверки: scripts/check-interactions.mjs (валидация, запрос, ошибки, подтверждение, повторная отправка, фокус, Escape, отзывы и размеры модальных окон), scripts/check-layout.mjs (адаптивность). Результаты: interaction-check.json и layout-check.json. Для запуска нужен локальный сервер на 5173 и установленный Chrome.

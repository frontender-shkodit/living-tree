# Исправления пунктов 1–4 аудита

## Контраст и доступность

Основной зелёный затемнён до #007B2A, hover до #006C24, скидочные цены до #B83B22, серые подсказки до #666666. Подписи бейджей имеют тёмную подложку; иконки управления и звёзды затемнены для читаемости. Фокус выделяется тёмно-голубым контуром. Исходные SVG не перерисованы.

Рейтинг получил role=img и подпись, поля — постоянные видимые labels, кнопки товаров — уникальные доступные имена. Skip-link переводит фокус в main. Новые отзывы объявляются через live status; на узких экранах обрезанная вторая карточка исключается из дерева доступности. Лишний буквальный `n удалён.

Автоматический production axe-аудит страницы, диалога и ошибок формы на 1920 и 360 px: 0 подтверждённых нарушений. Остались incomplete-проверки контраста на изображениях и фоне, требующие ручного просмотра; это не заявление о полном соответствии WCAG. Проверены сценарии заказа, фокус и 13 адаптивных ширин.

## SEO и пререндеринг

Обновлён title, добавлены meta description и текстовые Open Graph-метаданные. H1 теперь описывает товар — «живое дерево с кроной из цетрарии», визуальный лозунг сохранён. Production build формирует полный HTML с девятью товарами через React renderToString, затем клиент гидратирует страницу. Проверяется наличие каталога без JavaScript и отсутствие ошибок гидратации.

Canonical и абсолютные og:image/og:url зависят от будущего домена и относятся к пункту 5 исходного плана; вымышленные адреса не добавлялись. Серверная интеграция заявок остаётся отдельным этапом.

## Изображения
